# おみせのWeb係

南大沢・多摩エリアの小さなお店向けホームページ制作・更新サポートサービスです。

## 内容

- サービスサイト
- カフェ、美容室、ベーカリーの操作可能な架空制作サンプル
- PC・スマートフォン対応
- 月額プランとサポート範囲の案内

## ローカル確認

```bash
python3 -m http.server 4173
```

`http://localhost:4173` を開きます。

## 検証・ビルド

```bash
npm run check
npm run build
```

`dist/` にVercel公開用ファイルが生成されます。

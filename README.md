# tateken web

南大沢・多摩エリアの小さなお店向けホームページ制作サービスの公式サイト（初期版）です。

## ローカル確認

```bash
python3 -m http.server 4173
```

ブラウザで `http://localhost:4173` を開きます。

## 検証・ビルド

```bash
npm run check
npm run build
```

`dist/` にVercel公開用の静的ファイルが生成されます。
